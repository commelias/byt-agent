# byt-agent — контекст для Claude

Сервис-обвязка Telegram-агента «Быт» (Донна) на платформе AI-агентов Timeweb Cloud. Агент живёт в панели
Timeweb (аккаунт Евгения, агент ID 266187, Gemini 3.8 Flash); этот репозиторий — то, чего у платформы нет:
журнал с цифрами в PostgreSQL, планировщик событий, православный календарь, доставка точных текстов
в Telegram мимо модели. Подключается к агенту как MCP-сервер «Журнал» (`/mcp`, Bearer = `MCP_TOKEN`).

Пользователь агента — Евгений («Женя»), у него нет Claude: агент должен справляться сам. Сопровождает
Элиас (панель Timeweb, GitHub), код пишет Claude.

## Как устроено (IDEF0)

- Вход: сообщение Жени в Telegram; тик планировщика раз в минуту.
- Управление: системный промпт агента (v7, хранится в панели; копия — в проекте claude.ai) и навык
  «Справка о компании перед встречей».
- Механизм: модель (панель) · MCP «Журнал» (`app/mcp_server.py`, 26 инструментов) · часы
  (`app/scheduler.py`) · память (`app/db.py`, PostgreSQL; SQLite локально).
- Выход: ответ агента или сообщение сервиса в Telegram через очередь `outbox`.

Событие — единица планировщика: когда (`at`, `days`, `repeat_hours`, `max_per_day`), условие (`cond`
из закрытого списка), документ (`text` / `saved` / `calc`), отметка (`mark`, которую ждём от человека).
Ничего не отправляется внутри вызова инструмента — всё через `outbox` и один воркер. Подробнее — README.md.

## Правила работы с кодом

- Ветка `main`; деплой на App Platform запускается вручную из панели выбором коммита (автодеплоя нет).
  После смены набора инструментов в панели у MCP-сервера нажать «Обновить методы» и включить новые —
  они приходят выключенными.
- Секретов в коде нет и быть не должно — всё в переменных окружения (`.env.example`). Репозиторий публичный.
- `mcp<2` прибит намеренно (в 2.x переименован FastMCP). Параметры инструментов — без `Optional`,
  иначе Timeweb/Gemini не показывает инструмент.
- Проверка Host в MCP SDK отключена намеренно: сервер за публичным доменом, доступ закрыт Bearer.
- Таблицы и новые колонки создаются при старте; миграции — только добавляющие, данные не терять.
- Условия и вычисляемые документы — короткий закрытый список в коде; всё остальное — данные в таблицах,
  агент меняет их инструментами без правки кода.
- Длинный текст в Telegram режется на части в `telegram.py`; лимит ответа модели (4096) не ужимать.
- Коммиты — по-русски, одной фразой о смысле изменения (см. `git log`).
- Локальная проверка: `MCP_TOKEN=test python main.py` без `DATABASE_URL` — журнал в `byt.db`.

## Что решено и не делается

- Картинки в «Быте» — нет (убраны 14.09.2026); картинки — отдельный агент.
- Видеобот и прослойка к Polza AI — отдельный сервис, сюда не мешать.
- Официальный Timeweb Cloud MCP к агенту не подключать.
- Голосовые сообщения агент не принимает; решение отложено.
